# Security and privacy

Weekly Timetable Planner is a first-release learning app, not independently audited software. Its concrete trust assumptions and storage behavior are documented in README.md. Keep important originals backed up before trying any feature that writes an output file.

Use synthetic inputs when reporting bugs. Do not post credentials, private financial records, precise locations, screenshots containing personal information, or production configuration secrets in public issues. The app has no analytics/telemetry integrations. Network listeners, if any, bind to loopback by default; do not expose them publicly without adding the controls required by your deployment.

Report ordinary bugs in repository issues. For a vulnerability exposing private data, use GitHub private reporting if enabled, or establish a private contact with the maintainer before publishing details. No support response-time guarantee is implied. Test only systems and files you are authorized to use.
